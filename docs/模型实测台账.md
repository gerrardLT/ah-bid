## 〇、必读：价格口径不能混用

**限价与估算价是两个不同的子市场，下浮率差 3~18 个点。所有系数必须按口径分层。**

| 口径 | n | 全局中位 | 标准差 |
|---|---|---|---|
| 限价（最高投标限价） | 370 | **12.4%** | 9.5 |
| 估算（合同估算价） | 1,248 | **15.3%** | 10.6 |
| 混合 | 1,618 | 15.0% | 10.6 |

**差异验证**（不是样本选择偏差）：

| 判别 | 结果 | 结论 |
|---|---|---|
| 同一招标人内部（49 个两种口径都有的） | 组内差 **+2.3 点**（全局 +2.9） | 真实口径效应 |
| 控制招标人后（169 条子样本） | 限价 12.8% vs 估算 16.6%，差 **+3.8 点** | 真实口径效应 |

**但口径与城市完全混淆（无法用统计分离）**：

```
阜阳市  限价   0 / 估算 328 =  0%   → 估算
滁州市  限价   0 / 估算  98 =  0%   → 估算
淮南市  限价  10 / 估算  69 = 13%   → 估算
芜湖市  限价  55 / 估算 314 = 15%   → 估算
宣城市  限价  55 / 估算 140 = 28%   → 混合
安庆市  限价  34 / 估算  63 = 35%   → 混合
黄山市  限价 108 / 估算 134 = 45%   → 混合
铜陵市  限价  32 / 估算  27 = 54%   → 混合
宿州市  限价  67 / 估算  12 = 85%   → 限价
```

**所以「阜阳下浮 10.0%」这个数字里，混着「价格硬」和「全用估算价」两件事。**

**处理方式**：`web/caliber.json` 存三套系数（limit / estimate / mixed），模拟器按城市自动推断。

## 一、模型结构（当前版本）

```
中标下浮率 = f₁(招标人) + f₂(评标办法) + f₃(控制价档位) + f₄(项目类型)
             [口径作为分层维度，不做系数]
             + ε
```

**已排除的变量**：`投标人数`、`技术标权重`、`市场阶段`
**未验证的变量**：`澄清文件数`、`投标周期`

## 四、关键修正：城市效应是招标人效应的伪装

**原假设**：芜湖 30.5% vs 宿州 5.9%，城市差异巨大。

**验证**：
```
黄山整体中位 14.1%，标准差 6.2
  但同城内部：
    黄山市徽州区住建局     29.4%
    歙县新安江乡村发展     22.5%
    黄山区住建局          15.8%
    黄山旅游发展股份       13.6%
  同城内部差 15.8 点 > 城市整体标准差 6.2
```

**三条证据链**：

| 检验 | 结果 | 含义 |
|---|---|---|
| 招标人间极差 | 31.6 点 | > 城市间极差 24.5 点 |
| 稳定性排序 | 招标人 2.7 < 代理 3.8 < 城市 9.3 | 招标人是最小单元 |
| 跨城市招标人 | 0 个 | 完全嵌套，城市只是聚合 |

**结论**：「黄山下浮低」是假象——芜湖/黄山全市的低下浮，是因为当地多数项目来自「价格硬」的招标人。

## 十、模拟器决策逻辑（v3）

```
输入：控制价 + 类型 + 评标办法 + 招标人 + 城市 + 价格口径

① 选系数表
   口径 = 用户指定 或 按城市自动推断（city_hint）
   CT = CAL.limit | CAL.estimate | CAL.mixed

② 选基准（优先级）
   招标人（n≥2 且 波动<6）
   > 评标办法（当前口径 n≥5）
   > 档位×类型 交叉（n≥10）
   > 同类型（n≥10）
   > 同档位
   > 全局均值

③ 修正项
   城市修正 = 当前口径的城市中位 - 当前口径全局中位
   投标人数 = 0（实测无关）
   报价权重 = (pw-60)/10*1.8  ⚠推断
   工期弹性 = (days/中位-1)*8  ⚠推断
   自身策略 = 激进+5 / 稳健0 / 保守-5

④ 置信度
   若有招标人画像 → 看 n 和波动
   否则 → 看基准样本量 n

输出：建议报价 + 下浮率 + 区间 + 置信度 + 归因 + 判断 + 风险
```

**同一项目、不同口径，结果差 14 个点**（宿州 1500 万房建）：
```
限价口径：报价 1,294 万，下浮 13.7%，置信度 偏低（n=13）
混合口径：报价 1,081 万，下浮 27.9%，置信度 较高（n=215）
```
